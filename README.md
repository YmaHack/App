# אתגר יומי

אפליקציית Android ותוכנת Windows עצמאית למעקב אישי אחר אתגר יומי.

## מה יש עכשיו

- לוח עברי־לועזי עם הדגשת החודש העברי.
- סימון הצלחה/אי־הצלחה, ציון 1–10 והערה.
- רצף נוכחי, שיא אישי, הצלחות וממוצע.
- משפטי מוטיבציה ואיור.
- 5 ערכות נושא עם מצב כהה/בהיר.
- תזכורת בטלפון עם בחירת ימים ושעה.
- גיבוי ושחזור.
- שמירה מקומית גם אחרי עדכוני APK רגילים.
- תוכנת מחשב Windows עם אותם נתוני מעקב.
- סנכרון מקומי בין הטלפון למחשב דרך אותה רשת Wi‑Fi, בלי תלות באתר חיצוני או בשירות ענן.

## סנכרון טלפון ↔ מחשב

1. מתקינים ופותחים את תוכנת Windows.
2. בטלפון נכנסים ל"הגדרות" → "סנכרון עם המחשב".
3. מעתיקים מהתוכנה במחשב כתובת שמתחילה ב-http:// ומסתיימת ב-:39225.
4. שומרים את הכתובת ומבצעים סנכרון ראשון.
5. אפשר להפעיל "סנכרון אוטומטי" בטלפון.

הסנכרון עובד ברשת המקומית בלבד. אין לפתוח את שרת הסנכרון לאינטרנט.

הנתונים במחשב נשמרים בקובץ מקומי בתיקיית הנתונים של Windows של התוכנה, והאפליקציה בטלפון ממשיכה לשמור את הנתונים מקומית.
